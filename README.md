# fastapi-sec 

A lightweight **FastAPI security automation CLI** that helps developers run basic security checks on FastAPI projects.

This tool is designed to be:
- Simple
- Extensible
- Backend-developer friendly

---

## Features

- CLI-based interface
- Designed for FastAPI projects
- Extensible security checks (static analysis, misconfig detection, etc.)
- Beginner-friendly architecture

---

##  Installation (Local / Editable)

Clone the repository:


git clone https://github.com/<your-username>/fastapi-sec.git
cd fastapi-sec
